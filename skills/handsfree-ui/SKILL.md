# /handsfree-ui — 핸즈프리 상태 화면

화면은 듣기 프로그램 안에서 `127.0.0.1` 로만 뜨므로 듣기가 켜져 있어야 보인다. 경로 표기: `$ROOT` = 이 SKILL.md가 있는 디렉터리의 두 단계 상위(플러그인 루트).

## 여는 법

1. `$ROOT/scripts/handsfree/handsfree status` 로 듣기가 켜져 있는지 본다.
2. 꺼져 있으면 `$ROOT/scripts/handsfree/handsfree start` 로 켠다(화면을 보려는 요청이 곧 켜 달라는 뜻이다). 이 세션이 음성 입력 대상이 된다는 걸 한 줄로 알린다. 준비가 안 됐다고 나오면(`setup` 전) 그 이유를 전하고 `handsfree setup` 을 안내한다.
3. `$ROOT/scripts/handsfree/handsfree ui` 로 연다. Orca 탭을 못 열면 기본 브라우저로 연다. 출력된 주소를 알려 준다(기본 `http://127.0.0.1:8179/`, 포트는 설정 `ui_port`).

음성으로는 "헤이 클로드, 화면 열어 줘"로도 열린다.

## 화면

맨 위 상태 막대(스크롤해도 붙어 있음)와 알림 띠(긴 말 받아쓰기·되묻는 중·승인 대기)는 늘 보이고, 나머지는 탭으로 나뉜다. 브라우저 탭 제목에도 상태가 나온다.

- 지금: 방금 들은 말과 결과(✓ 한 일 / ✕ 하지 않은 일과 이유), 그 뒤 호출어 없이 들린 소리 수, 세션 타일(입력 대상·작업 중·승인 대기와 무엇을 묻는지)
- 기록: 들은 말과 결과 묶음. 호출어 없는 소리는 이어진 것끼리 한 줄로 접는다
- 설정: 호출어(바꾸면 받아쓰기가 달리 적을 비슷한 소리를 저절로 채운다)와 알아듣지 못한 호출 추천(누르면 변형에 넣는다), 듣기·보내기·읽어 주기·소리 값, 세션 별명, 단축 명령. 바꾸면 `~/.ai-harness/handsfree/config.json` 에 바로 저장되고 다음 말부터 적용된다. 기본값과 다른 항목은 하나씩, 또는 "전체 기본값으로"(두 번 눌러야 실행)로 되돌린다. 설명은 항목에 마우스를 올리면 말풍선으로 뜬다
- 말하는 법: 동작별로 쓸 수 있는 말

## 지키는 것

- 이 맥에서만 열린다. 설정 저장 요청은 같은 출처·JSON·전용 헤더를 요구해 다른 웹 페이지가 값을 바꾸지 못한다.
- 명령 말 목록(`commands`)은 화면에서 바꿀 수 없다. 호출어는 세 글자 미만이거나 명령 말과 겹치면 거부한다.
- 화면을 보는 사람이 있을 때만 세션 상태를 읽는다.

## 고칠 때

화면은 `$ROOT/scripts/handsfree/ui.html`, 상태를 내주고 설정을 받는 서버는 `ui.py`. 화면만 고쳤으면 새로고침으로 반영되고, `ui.py` 를 고쳤으면 `handsfree stop` 뒤 `start`. 새 설정을 화면에 내려면 `ui.py` 의 `SETTINGS` 에 범위와 함께 추가하고 `defaults.json` 에 기본값을 둔다(`tests/handsfree/test_settings.py` 가 빠진 기본값을 잡는다).
