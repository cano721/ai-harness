# /handsfree — 말로 세션 조작하기

듣는 건 백그라운드 프로그램이고, 이 스킬은 그걸 켜고 끄고 설정한다. 인자: `$ARGUMENTS` — 없으면 `status` 를 보여 주고 꺼져 있으면 `start`, 있으면 그 명령.

경로 표기: 아래 `$ROOT` = 이 SKILL.md가 있는 디렉터리의 두 단계 상위(플러그인 루트). 사용자 데이터는 `~/.ai-harness/handsfree/`.

필요한 것: macOS, Orca(세션 목록·입력·화면 읽기에 `orca` CLI를 쓴다), Python 3(표준 라이브러리), Homebrew(`sox`·`cmake`), git·Xcode 명령줄 도구(받아쓰기 서버 빌드). 처음 켤 때 Orca 에 마이크 권한을 준다.

소리는 기기 안에서만 받아쓴다. 받아쓴 글은 두 경우에 밖으로 나간다: 프롬프트로 세션에 보낼 때, 그리고 승인 창이 떠 있는데 정해진 말이 아니라 뜻을 짐작할 때와 답변을 요약해 읽을 때(`claude -p`).

## 명령

`$ROOT/scripts/handsfree/handsfree <명령>`

| 명령 | 하는 일 |
|---|---|
| `setup` | `sox`·`cmake` 설치, whisper.cpp 받아쓰기 서버 빌드(`~/.ai-harness/handsfree/bin`), 모델 내려받기(약 570MB). 처음 한 번 |
| `start` | 듣기 시작. 꺼져 있다가 켜면 실행한 세션이 음성 입력 대상이 된다 |
| `stop` | 듣기 종료. 음성으로는 끌 수 없다(쉬기만 된다) |
| `status` | 켜짐 여부, 호출어, 세션 번호(▶ 가 입력 대상) |
| `hooks` / `statusline` | 읽어 주기용 훅(Stop·PermissionRequest·Notification·UserPromptSubmit)과 상태 표시줄의 "🎙 듣는 중" 표시를 `~/.claude/settings.json` 에 넣는다. 처음 한 번 `.handsfree.bak` 으로 백업하고, 고정 경로 연결 스크립트(`~/.ai-harness/handsfree/bin/`)를 가리키므로 플러그인을 업데이트해도 끊기지 않는다. 새로 연 세션부터 적용 |
| `unhook` | 위 둘을 걷어 내고 상태 표시줄을 원래 명령으로 되돌린다 |
| `ui` | 상태 화면을 Orca 탭으로 연다(handsfree-ui) |
| `log` | 최근 인식·동작 기록 |
| `check <wav>` | 녹음 파일의 받아쓰기와 분류 결과만 본다. 세션에는 보내지 않는다 |

`hooks`·`statusline` 은 사용자 설정을 고치므로 사용자가 원할 때만 실행한다.

## 말하는 법

"헤이 클로드, ~" 뒤의 말이 아래와 같으면 조작, 아니면 현재 세션에 프롬프트로 보낸다. 말 전체가 정해진 말과 같아야 조작이다("좋아 그럼 PR 올려"는 프롬프트). 전체 목록은 `scripts/handsfree/defaults.json` 의 `commands`.

| 말 | 동작 |
|---|---|
| 승인 / 거절(하지 마) / N번 | 승인 창·선택지에 답한다 |
| N번 세션 승인 · (별명) 승인 | 다른 세션의 창에 답한다 |
| 확실히 승인 | 위험 명령 창 승인 |
| 뭐 승인하는 거야 | 창 내용 읽기 |
| 중단 / 방금 거 취소 | Esc. 뒤쪽은 방금 보낸 세션으로 |
| N번 세션 · 다음 세션 · (탭 이름) 세션 · (별명)로 가 | 입력 대상 바꾸기 |
| N번 세션에 ~ · (별명)에 ~ | 대상은 그대로 두고 그 세션에만 보내기. 탭 이름으로 가리키면 되묻는다 |
| 길게 말할게 | 긴 말 모드. 이어 말한 것을 모았다가 "보내"·"끝"이면 보내고 "취소"면 버린다 |
| N번 끝나면 알려 줘 | 그 세션이 끝나거나 승인을 기다리면 한 번 소리로 알린다 |
| 읽어 줘 · 계속 읽어 줘 · 요약해 줘 · 조용 | 마지막 답변 읽기·요약·멈춤 |
| 세션 상태 · 듣고 있어? | 승인 대기·작업 중인 세션, 듣기 상태 |
| 잠깐 꺼 · 5분 쉬어 · 다시 켜 | 쉬기와 다시 듣기 |
| 화면 열어 줘 | 상태 화면 열기 |

"헤이 클로드"만 부르고 8초 안에 이어 말해도 된다. 그때 한 말은 프롬프트면 보내고, 승인·선택·엔터는 받지 않는다. 되묻는 말("보낼까요?")에는 "보내"·"아니"처럼 호출어 없이 답해도 된다(한 글자 대답은 호출어가 필요하다).

## 안전 규칙

세션이 자동 승인 모드면 잘못 들어간 말이 곧바로 실행된다. 아래는 일부러 막아 둔 것이니 사용자가 풀어 달라고 하지 않으면 유지한다.

- 호출어 없는 말은 실행하지 않는다. 예외는 호출어만 부른 직후 8초 안의 프롬프트와 되묻는 말에 대한 정해진 대답뿐이다.
- Claude Code 입력 칸이 보일 때만 글자와 엔터를 보낸다. 승인 창이 떠 있거나 화면을 읽지 못하면 보내지 않는다 — 엔터가 승인으로 먹기 때문이다.
- "승인"은 1번이 Yes 이고 커서가 거기 있을 때만 통한다. 질문형 선택지는 번호로 고른다.
- "앞으로 묻지 않음"류 선택지(`broad_option_patterns`)는 음성으로 고를 수 없다. 위험 명령(`danger_patterns`)은 "확실히 승인"이 필요하다.
- 현재 세션에 창이 없고 다른 세션에 있으면 승인 말을 보내지 않고 어느 세션인지 알려 준다.
- AI 판단은 승인 창이 떠 있을 때만 쓰고, 결과는 되물은 뒤 실행한다.
- 하지 않은 일은 읽어 주기 설정과 상관없이 소리로 알린다. 조용한 시간에도 끄지 않고 작게만 낸다.
- 승인 말에 "어·응·해·네·계속·확인" 같은 짧거나 뜻이 갈리는 말을 넣지 않는다. 말이 끊겨 앞부분만 들어가면 승인이 된다.

## 설정

자주 바꾸는 값은 상태 화면의 설정 탭에서 바꾼다(handsfree-ui): 호출어(알아듣지 못한 호출 추천 포함), 단축 명령, 세션 별명, 말 끝 기다림·마이크 기준선·첫마디 여유, 보내기 전 확인, 읽어 주기·요약·소리 크기·조용한 시간.

기본값은 `scripts/handsfree/defaults.json`, 사용자 설정은 `~/.ai-harness/handsfree/config.json`. 사용자 설정에 적은 키만 기본값을 덮고, 저장하면 다음 말부터 적용된다(모델·포트는 다시 켜야 한다). 명령 말 목록(`commands`)은 안전 규칙과 얽혀 화면에서는 못 바꾸고 이 파일로만 고친다.

```json
{
  "wake_words": ["자비스"],
  "commands": { "interrupt": ["멈춰", "스톱"] },
  "macros": { "커밋": "/commit" },
  "aliases": { "결제": "결제 리팩터링" },
  "vocabulary": ["Jira", "PR"]
}
```

- `commands`: 적은 동작만 통째로 바뀐다. 기본 목록에 더하려면 기본 말까지 같이 적는다.
- `vocabulary`: 자주 틀리게 받아쓰는 용어. 호출어는 받아쓰기 힌트 맨 앞에 저절로 들어간다.

## 안 될 때

| 증상 | 확인 |
|---|---|
| 아무 반응 없음 | `log` 에 줄이 쌓이는지. 안 쌓이면 시스템 설정 > 개인정보 보호 > 마이크에서 Orca 허용 |
| 받아쓰긴 하는데 무시 | 상태 화면 설정 탭의 "알아듣지 못한 호출"을 눌러 변형으로 넣거나 `log` 의 `ignore ←` 앞머리를 `wake_words` 에 추가 |
| 말해도 안 잡힘 / 조용한데 녹음 | 마이크 기준선을 낮추거나 올린다. 상태 화면의 음량 막대가 기준선을 넘는지 본다 |
| 말이 중간에 끊겨 전송됨 | 말 끝 기다림을 늘리거나 "길게 말할게"로 시작한다 |
| 첫마디가 잘려 호출어를 못 알아들음 | 첫마디 여유를 늘린다. `debug_samples` 에 숫자를 주면 최근 녹음이 `~/.ai-harness/handsfree/samples/` 에 남는다(집 안 소리가 담기니 확인 뒤 끈다) |
| 엉뚱한 세션으로 감 | 입력 대상은 음성으로 바꾼 세션, Orca 에서 클릭해 앞에 띄운 탭, 키보드로 프롬프트를 친 세션을 따라간다. 화면을 여러 칸으로 나눠 보면 클릭은 따라가지 않으니 "N번 세션"으로 맞춘다 |
| 읽어 주기가 안 나옴 | `hooks` 실행 여부, 그 뒤에 연 세션인지, 답변 자동 읽기를 켰는지 |
