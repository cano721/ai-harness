# /session — 세션 단위 사용 리포트

경로 표기: `$ROOT` = 이 SKILL.md가 있는 디렉토리의 두 단계 상위(플러그인 루트).

인자: `$ARGUMENTS` — 세션 id 앞부분 (생략 시 `latest` = 지금 이 세션. 이 스킬을 실행하는 세션의 transcript가 항상 가장 최근 수정 파일이므로 latest가 곧 현재 세션이다).

## 절차

1. 리포트 생성:
```bash
$ROOT/scripts/session.sh [인자]
```

2. 출력된 표를 그대로 붙이지 말고 요약: 한 줄 개요(턴·토큰·주 활동) → 눈에 띄는 포인트 2~3개만.
   - 토큰 비대 원인 (특정 파일 반복 편집, 대용량 Read 등)
   - docs/워크플로를 거쳤는지 vs 직접 편집했는지
   - error·guard_block·교정 마크가 있으면 그 지점 코멘트
3. 진행 중 세션이면 "현재까지" 기준임을 명시. 다른 세션과의 비교가 필요하면 `/metrics` 안내.
