### 버그 수정

- **러너가 멈춘 뒤 밖에서 마무리한 작업이 보드에 끝남으로 정리됩니다** — 러너 상태에 작업 브랜치가 publish 뒤에만 남아, publish 전에 멈춘 런은 같은 브랜치의 PR이 밖에서 병합·닫혀도 보드에 '사람 필요'·'중단됨'과 이어 가기 명령이 그대로 남았습니다. (#605)
  요약: 러너가 시작할 때 작업 브랜치를 기록하고, 보드는 PR 주소가 없는 멈춘 러너 카드도 브랜치로 PR을 찾아 병합·닫힘이면 끝남으로 내립니다. 릴리스 런은 origin에 태그가 있으면 끝남으로 봅니다. 열린 PR·조회 불가·develop·main 같은 공용 브랜치는 그대로 둡니다.
