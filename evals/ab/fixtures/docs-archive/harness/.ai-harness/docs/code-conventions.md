# 코드 컨벤션

- DB 접근은 `archive/repository.py` 함수 또는 잡 안의 SQL로 한다. 시각은 `'YYYY-MM-DD HH:MM:SS'` 문자열로 저장·비교한다.

### 대량 조회 메모리

배치·스윕·스케줄 잡·내부 일괄 API처럼 한 실행·요청이 다건을 읽는 경로에 적용한다. 메모리는 "건수 상한 × 행 크기"로 커진다.

- 판정·집계만 하는 다건 조회는 행을 통째로(`SELECT *`, `find_documents_by_status`) 읽지 않는다. 필요한 컬럼만 SELECT 컬럼 목록으로 읽는다.
- `documents.body` 같은 대형 컬럼을 목록으로 읽어야 하면, 그 컬럼이 필요한 근거를 조회 함수 주석에 남긴다.
- 일괄 조회는 SQL에 항상 상한(`LIMIT`, keyset 페이징)을 둔다. 조건 없는 무제한 전체 조회 금지. 한 번에 최대 500행.
