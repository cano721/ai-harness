# 개인정보 처리 안내 — 보드 '내 일정'

ai-harness 보드의 '내 일정' 화면이 무엇을 읽고 어디에 두는지 적습니다. 이 기능은 사용자가 연결할 때만 동작합니다.

## 읽는 데이터

- **구글 캘린더**: 일정 읽기만 합니다. 요청하는 권한(scope)은 `https://www.googleapis.com/auth/calendar.readonly` 하나입니다. 일정을 만들거나 고치거나 지우지 않습니다.
  - 읽는 범위: 연결한 계정마다 구글 캘린더에서 "표시"로 고른 캘린더의 오늘 0시부터 7일 동안의 일정(제목·시작·끝·캘린더 이름·일정 링크).
  - 계정 구분: 연결할 때 그 계정의 기본 캘린더 주소(보통 구글 계정 이메일)를 읽어 계정 이름으로 씁니다. 같은 권한 안에서 읽으며 다른 프로필 정보는 요청하지 않습니다.
- **스킬이 제공하는 어댑터**: 사용자가 [연결]을 누른 어댑터가 내는 항목(제목·시각·링크·짧은 설명)만 받습니다. 어댑터가 외부 서비스에서 무엇을 읽는지는 그 어댑터를 제공한 스킬이 정합니다.
- **직접 적은 할 일**: 보드 입력 칸이나 `board.sh todo`로 적은 내용.

## 저장 위치

모두 이 PC의 `~/.ai-harness` 아래에 두고, 파일 권한은 소유자만 읽고 쓰는 600입니다.

| 파일 | 내용 |
|---|---|
| `~/.ai-harness/google-oauth-client.json` | (선택) 사용자가 직접 만든 OAuth 클라이언트. 있으면 공용 클라이언트 대신 씁니다 |
| `~/.ai-harness/board/agenda/google-accounts/<계정>.json` | 계정별 구글 접근·갱신 토큰(폴더 700) |
| `~/.ai-harness/board/agenda/sources.json` | 어느 소스를 연결했는지 |
| `~/.ai-harness/board/agenda/cache/<소스>.json` | 마지막으로 가져온 항목 |
| `~/.ai-harness/board/agenda/done.json` | 보드에서만 완료로 표시한 항목 |
| `~/.ai-harness/board/agenda/todos.json` | 직접 적은 할 일 |

일정·메시지 내용은 하네스 자동 개선(harvest)이나 사용 지표 수집 대상이 아닙니다.

## 보내는 곳

- 중개 서버가 없습니다. 보드는 구글 API에 이 PC에서 바로 요청하고, 토큰 교환도 이 PC에서 합니다.
- 플러그인에는 공용 데스크톱 OAuth 클라이언트(`scripts/board/agenda/google/client.json`)가 들어 있습니다. 데스크톱 앱의 client secret은 구글도 앱 안에 넣어 배포하는 값으로 보고 기밀로 다루지 않습니다. 대신 연결할 때마다 PKCE(일회용 확인 값)와 state 확인, 사용자의 직접 동의를 거치므로, 이 클라이언트 값만으로는 누구의 일정도 읽을 수 없습니다. 공용 클라이언트를 만든 쪽(저장소 관리자)도 토큰과 일정을 받지 않습니다 — 토큰은 이 PC에만 있습니다.
- 자기 Google Cloud 프로젝트의 클라이언트를 쓰려면 `~/.ai-harness/google-oauth-client.json`에 둡니다(`/ai-harness:setup` 8-4).
- 읽은 데이터를 제3자에게 보내지 않습니다. 보드 화면은 이 PC(127.0.0.1)에서만 열립니다.

## 연결 끊기와 토큰 폐기

- 보드 '내 일정 → 연결한 곳'에서 계정의 [끊기]를 누르면 그 계정의 토큰 파일을 지우고, 구글에 권한 철회(revoke)를 한 번 요청합니다. 네트워크가 없어 철회 요청이 실패해도 로컬 토큰은 지워집니다. 마지막 계정을 끊으면 구글 캘린더 연결도 끊깁니다.
- 구글 쪽에서 직접 끊으려면 Google 계정 → 보안 → "타사 앱 및 서비스"(타사 액세스)에서 ai-harness 보드 앱의 액세스를 해제합니다.
- 남은 파일을 모두 지우려면 위 표의 파일을 삭제합니다.
